# Pixel world prototype

This is original code-drawn art, not copied game art. The world uses a limited palette, pixel-grid silhouettes, a floating book, a keeper, two connected islands and a hidden cellar. The narrow view independently places the observatory behind the island.

The generator is `scripts/pixel_world.py`. It returns a self-contained SVG in static, ambient and character-motion variants. Reduced-motion CSS stops decorative animation. Pillow is required to draw the pixel grid. Local previews included static PNGs and frame-based GIF sketches; GIFs were approximations and did not establish GitHub SVG animation support. This early code-drawn study was superseded by the [Midnight Workshop](midnight-workshop.md).

**Status: visual prototype, not accepted.** The composition still needs an art gate. In particular, the main building retains a symmetric house silhouette.
