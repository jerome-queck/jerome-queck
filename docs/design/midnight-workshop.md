# Midnight workshop

The page moves through one cutaway workshop. The text and source links are real HTML links surrounding SVG views, so each project is independently clickable. The website projects link their titles to their websites and their source buttons to their repositories. The other project titles link to their repositories. A native text edition carries all project links and descriptions when images are unavailable. Wide and narrow masters compose the scene separately. Native reduced-motion picture sources select static masters. The still and animated masters share the same resting frame; only small decorative lights animate.

The original scene in `assets/pixel-world/workshop-original.png` was generated for this profile with OpenAI ImageGen. `workshop.jpg` is a 900-pixel, quality-55 JPEG conversion used in the masters (`sips -s format jpeg -s formatOptions 55 --resampleWidth 900 assets/pixel-world/workshop-original.png --out assets/pixel-world/workshop.jpg`). `scripts/render_readme_world.py` composes its views, labels, light and source buttons. The image contains no live data. Typography uses pinned local OFL sources in `assets/type/manifest.json`, outlined into the masters.

The data room uses the same plum, timber and gold palette and a faint JPEG crop of the workshop cellar. The all-time counters, monthly merges, contribution calendar, activity mix, merged PR numbers, upstream patch footprint, open proposal ages and aggregate language bytes all come from the completed schema-3 snapshot. Patch statistics describe entire merged PRs and all their contributors; file changes can repeat. Proposal ages count completed days at the snapshot time. Language bytes describe contents, not expertise. Exact records, definitions and links remain in the native text snapshot.

Fifteen required data payloads publish in one Git commit: nine individual SVGs, four data-room SVGs, `snapshot.json` and its native `README.md`. Missing payloads prevent publication. Failed collection or rendering retains the prior snapshot and timestamp. Separate CDN caches may refresh at different times.
