# Art, navigation and projects

## Sub-features

Actual profile avatar; continuous illustrated canvas assembled from sixteen responsive images; four software title links and five website title links with secondary repository buttons. Native disclosure preserves all nine names, descriptions and sources. Source is `README.md`, `data/projects.json`, `scripts/render_interface.py`, `assets/pixel-world/` and `docs/design/midnight-workshop.md`.

## How to get to it (user POV)

Click each illustrated project title. Software titles open repositories; mathematics titles open websites. Each mathematics row also has a repository button. Open the text edition for ordinary descriptions, sources, upstream receipts and provenance.

## Driving it with Playwright

Run both GitHub surfaces in the skill. The driver clicks all nine actual image-title anchors and all five actual source buttons, preserving expected href, response, final URL, screenshot and page text. Duplicate native fallback links do not substitute for image-title clicks. Anonymous website access blocked by 401/403 is verified-unreachable, never proof that a site is down. Avatar capture on the actual profile is separate evidence; compare against approved artwork manually.
