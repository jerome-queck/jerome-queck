## Mathematics

Notes, visual explanations and tools I use to explore the subject.

- [Calculator](https://calculator.jeromegroup.org). Symbolic computation, notebooks and plots. The site requires sign-in. [Source](https://github.com/Jerome-Group/calculator).
- [Probability](https://probability.jeromegroup.org). A first course in probability, published as mathematical notes. [Source](https://github.com/jerome-queck/probability).
- [Number theory](https://numbertheory.jeromegroup.org). An interactive atlas of elementary number theory. [Source](https://github.com/Jerome-Group/numbertheory).
- [Algebra](https://algebra.jeromegroup.org). Groups, rings, fields and representations, with visual explanations and interactive explorations. [Source](https://github.com/Jerome-Group/algebra).
- [Calculus](https://calculus.jeromegroup.org). Limits and derivatives through multivariable and vector calculus, with interactive graphs and geometry. [Source](https://github.com/Jerome-Group/calculus).

## Software

- [Academic OS](https://github.com/Jerome-Group/academic-os). Module and research folders, tasks, calendars and the information behind my academic dashboard.
- [NTULearn Sync](https://github.com/Jerome-Group/ntulearn). Local NTULearn course copies, with Markdown pages, announcements and attachments in their course folders.
- [Syrax](https://github.com/Jerome-Group/syrax). My personal Telegram assistant, built on OpenClaw. Its repository holds setup, configuration and a runtime adapter.
- [Emmy](https://github.com/jerome-queck/emmy). My chief-of-staff operating kit for ChatGPT Dot. Local context, evidence checks and advisory routing, with execution and permissions owned by the native products.
